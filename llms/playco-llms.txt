# Playco

> Instant-play gaming company (founded 2020, HQ Tokyo) building HTML5 games that run inside social and
> communication platforms with no app install — EverWing on Facebook, Snake Squad on Snap Games, Heads Up!
> for Zoom, Sway Stories on TikTok, Trip Royale on LINE. Playco publishes NO public API: no developer
> portal, no API reference, no OpenAPI/AsyncAPI/GraphQL/MCP surface and no base URL. Its developer-facing
> technology is client-side game tooling, and its public code lives in the play-co GitHub organization
> (the renamed Game Closure organization).
>
> Generated by API Evangelist from apis.yml and the artifacts in this repository. Nothing here is authored
> on Playco's behalf; every link below was fetched and its status recorded.

## Notes for agents
- There is nothing to call. Do not construct a Playco API base URL; api.play.co does not exist.
- The security.txt served at support.play.co/.well-known/security.txt belongs to Intercom
  (Canonical: app.intercom.com), not to Playco. Do not report vulnerabilities to it as Playco's program.
- GCInstant, Replicant and Odie3D are named on play.co/tech but are not published to any package registry.
- The npm package @playco/ng-api is PlayNetwork's, not Playco's.
